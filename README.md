# 衣序 · 个人穿搭系统 V0.1A

一个以“学 / 看 / 我的”为核心的穿搭学习型 Web App。使用本地静态内容和浏览器 localStorage，不包含登录、数据库、AI、衣橱、购买判断或穿搭评分。

## 启动与验证

```bash
pnpm install
pnpm dev
```

访问 http://localhost:3000。当前代码使用 Next.js 16.3.5、React 19、TypeScript 和 Tailwind CSS 4。

```bash
pnpm test       # 内容关系、素材完整性、损坏记录恢复
pnpm typecheck
pnpm lint
pnpm build
pnpm start
```

`pnpm check` 依次运行测试、类型检查、lint 和构建。

可选的真实浏览器回归使用 Playwright 与本机 Microsoft Edge，覆盖桌面/手机布局、按钮对比度、学习状态刷新、收藏编辑、A/B、键盘操作、无效路由及损坏记录：

```bash
node tests/browser-smoke.mjs
```

此脚本需要环境中可解析 `playwright`；也可通过 `PLAYWRIGHT_MODULE_PATH` 指向已安装的模块目录，`BROWSER_CHANNEL` 指定其他已安装的 Chromium 浏览器，`BASE_URL` 指定服务地址。截图写入被 Git 忽略的 `.qa/`。

## 页面

- `/`：今日继续、穿搭案例、最近学到
- `/learn`：平级的基础原理 / 单品知识入口，六个单品分组
- `/learn/[id]`：核心解释、观察线索、判断、原因、误区、真人应用与一个 takeaway
- `/explore`：案例流、A/B 入口、我的收藏
- `/explore/compare`：四组真人照片对比，先判断、再解释
- `/explore/[id]`：整体印象、1～3 个因素与默认展开的七项分析
- `/me`：学习记录、收藏笔记、减少动态效果和本地重置

## 内容与图片

`lib/data.ts` 包含 23 篇课程、15 个案例及 4 组对比。六篇基础原理与衬衫、T恤、直筒裤、阔腿裤、乐福鞋、复古薄底运动鞋均有完整学习结构。原有补充课程与案例继续保留。

`lib/photos.ts` 保存本地文件、alt、作者、来源、原图 URL 与许可链接。已核实的作者才填写姓名；历史素材作者不明时保留 `null`，部分旧 Unsplash 素材目前以原图 URL 作为来源入口。图片来自原有素材与 Pexels / Unsplash，未用生成图片冒充真人照片。

单品、材质和风格课程使用真人应用图。抽象的腰线、裤宽和色彩关系保留示意图。A/B 照片来自不同拍摄条件，页面明确标注主要观察重点与其他影响因素，不宣称是严格单变量实验。衣物描述仅依据可见画面，不推断面料成分、触感或人物身份。

## 博主观察与实操教程

新增痴五安chammy、AYUANPL阿源匹林各一条经核对原作的截图案例。作者、原作链接、发布时间、截帧时间与来源语境保存在 `lib/creator-content.ts`，出处记录见 [docs/creator-sources.md](docs/creator-sources.md)。截图完整保留原文字，不去除水印，不进行调色，也不将作者素材标注为图库许可。

- `/explore` 支持按这两位博主筛选；案例详情可返回作者主页和原作。
- `/learn/read-creator-outfits`：分开观察衣物关系与机位、光线、姿势。
- `/learn/layering-openings`：从领口、前襟、下摆理解叠穿。
- `/learn/trouser-shoe-break`：结合裤口、裤长与鞋面观察收尾。
- 比例、色彩、轮廓、T恤、外套、鞋履课程增加了相关博主案例与三步实操。练习勾选用于当页自查，原有“学过 / 我理解了”仍用于保存学习状态。

两个博主的截图不组成新的 A/B 实验，也不把不同场景的镜头当作穿搭变化的因果证据。教程和案例分析为本站原创观察，原视频字幕不等于本站结论。

## 本地记录兼容

沿用 `style-notes-v01a` 与原课程、案例 ID。学习、理解、收藏原因、笔记与设置保存在当前浏览器；无法同步到其他设备。恢复时过滤无效日期、错误选项与损坏结构，保留其他有效记录。

替换照片后的四组 A/B 使用新的对比 ID，避免把旧照片上的判断误记到新照片；旧判断仍保留在原本地数据中。浏览器禁止存储时，页面显示说明，并允许继续在当前会话学习。
